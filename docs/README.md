# Installation notes


## Building and running backend:

* **From terminal:** Ensure the repository folder is open, and then run:

    <code>cd backend && chmod +x ./gradlew && ./gradlew run</code>


* **From IntelliJ IDEA:**

    Directly run the main method at **backend/src/main/java/edu/gcc/ramraiders/Main.java**

## Building and running frontend:

Make a new folder.

<code>git clone https://github.com/haddonbaker/frontend.git</code>

<code>cd frontend/frontend</code>

<code>npm install</code>

<code>npm run dev</code>

Open http://localhost:5173/
