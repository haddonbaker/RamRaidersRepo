# 📦 Project Requirements

This document lists the requirements for the project.
It is expected to change as requirements are refined.

---

## 🚀 MVP Requirements

- [ ] **R1 – Schedule Add**  
  A user should be able to add a course to a candidate schedule.

- [ ] **R2 – Schedule Persistence**  
  The system shall allow a user to save a schedule and reload it at a later date

- [ ] **R3 – Schedule Search**   
  A user should be able to search for available courses

- [ ] **R4 – Search Filter**   
  A user should be able to restrict the search results based on the following preferences:
    - R4a -  Course code
    - R4b -Course name or description key word or words (e.g. psychology)
    - R4c -Professor name
    - R4d -Department
    - R4e -Number of credits
    - R4f -Days and time range. Eg: I should be able to restrict results to MWF after 10am.
 

- [ ] **R5 – Schedule Remove**   
  A user should be able to remove courses from their candidate schedule

- [ ] **R6 – Schedule Conflicts**   
  The user should not be able to add a course to their candidate schedule that has a time conflict with a class that is already on the candidate schedule

- [ ] **R7 – Schedule Visualization**   
  The software should have a visual depiction of the candidate schedule in a weekly format

- [ ] **R8 – Schedule User Interface**   
  The software should have a front end that gives the user a graphical user interface

- [ ] **R9 – Schedule Error Handling**   
  The software should not crash due to any user input

- [ ] **R10 – Schedule Conflict Resolution**   
  The user will receive suggestions of alternate class periods in order to resolve scheduling conflicts
---

## ✨ Additional Features

-[ ] **F1 – Dark mode**  
  A user can toggle dark mode where the app background will become dark themed.

-[ ] **F2 – User Profile**  
A user can add or edit personal information in their profile, possibly including  major, advisor email, year, courses taken.

- [ ] **F2 – Advisor Email**   
  If a user has entered advisor email into their profile, they may send their schedule to their advisor.

- [ ] **F3 – Schedule Export**   
  A user can choose to export their schedule to an easily readable PDF

- [ ] **F4 – Course Overload**   
  A user will be alerted if the scheduled course load is above maximum of credits

- [ ] **F5 - Personalized Search**  
  A user can choose to rank search results based on major requirements, already taken classes being greyed out with hover helptext.
